# Anomaly Detection and Statistical Analysis
One of my main goals was to prepare, clean, and process the data to make it more usable for analysis using Pandas. Along with that, I performed statistical analysis, anomaly detection, and later manual review of data records to ensure data quality. 

I performed a statistical analysis of given RA (Registration Authority) and VA (Validation Authority) (including OtherVA) in the LEI (Legal Entity Identifier) dataset with respect to their Jurisdiction and ManagingLOU to identify outliers in RA code usage for further manual inspection and challenge. I also analyzed the relationship between RA and VA fields (e.g. if (or if not) fields are referring to the same authority).
